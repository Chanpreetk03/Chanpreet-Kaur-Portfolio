# Chanpreet Kaur Portfolio

A responsive portfolio built with Vite, Three.js, HTML, CSS, and JavaScript. The hero scene is a custom WebGL sculpture; project, experience, and education content stays editable in arrays.

## Run locally

Requires Node.js 20 or newer.

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; Vite writes the site to `dist/`. Run `npm run preview` to inspect that build locally. The relative asset base supports publishing the `dist/` output to GitHub Pages.

## Update content

Edit `data.js`. Projects, experience, achievements, and education are arrays in `portfolioData`; add an object to the relevant array, save, and reload the page.

### Add a project

```js
{
  title: "Project name",
  category: "Web application",
  year: "2026",
  description: "A short description of what it does.",
  technologies: ["React", "TypeScript"],
  visual: "auth",
  featured: false,
  links: [
    { label: "View source", url: "https://github.com/username/project" }
  ]
}
```

Available project preview styles are `codex`, `auth`, and `dj`. Set `featured: true` for the wide featured layout. `technologies` and `links` accept multiple values.

### Add experience

```js
{
  period: "Jan 2025 — Present",
  title: "Organization or project",
  role: "Your role",
  type: "Full-time",
  description: "A short summary of your work.",
  highlights: ["A result, responsibility, or useful detail."]
}
```

`highlights` is optional. Set `type` to values such as `Full-time` or `Internship`.

### Add an achievement

```js
{
  year: "2025",
  title: "Competition or award",
  recognition: "Team winner",
  description: "A short description of the achievement.",
  scale: "18,000+",
  scaleLabel: "people registered"
}
```

Use the `scale` and `scaleLabel` fields for a notable participation or impact figure; otherwise set them to an empty string.

### Add education

Add entries to the `education` array using the same timeline fields:

```js
{
  period: "Dec 2021 — Sep 2025",
  title: "Punjab Engineering College",
  role: "Bachelor of Technology · Electrical",
  type: "Degree",
  description: "Activities, societies, or other details."
}
```

The project and timeline markup is generated by `app.js`; layout lives in `index.html`, responsive styling in `style.css`, and the Three.js hero is in `scene.js`.

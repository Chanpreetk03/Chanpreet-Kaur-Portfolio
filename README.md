# Chanpreet Kaur Portfolio

A responsive portfolio built with Vite, Three.js, HTML, CSS, and JavaScript. The hero is a custom WebGL sunrise; projects, experience, achievements, and education stay editable in arrays.

Portfolio content is prerendered into the built HTML for search engines and readers that do not execute JavaScript. The same render helpers hydrate the page in the browser from `data.js`.

## Run locally

Requires Node.js 20 or newer.

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; Vite writes the site to `dist/`. Run `npm run preview` to inspect that build locally. GitHub Pages deployment is configured in `.github/workflows/deploy.yml`; in repository Settings → Pages, set the publishing source to **GitHub Actions**. Pushes to `main` build and deploy `dist/`.

## Search and sharing

- `robots.txt` allows public crawling and points crawlers to `sitemap.xml`.
- `sitemap.xml` lists the canonical portfolio URL.
- `llms.txt` provides a concise, maintained plain-text profile and project summary for AI readers.
- `index.html` contains canonical, Open Graph, Twitter, and Schema.org Person/WebSite metadata.
- `public/images/og-cover.jpg` is the landscape link-preview image; `public/favicon.svg` and `public/site.webmanifest` provide browser identity metadata.

After deployment, add the canonical site URL to Google Search Console or Bing Webmaster Tools and submit the sitemap. Crawling and indexing are controlled by those services and can take time; metadata does not guarantee a particular ranking.

## Update content

Edit `data.js`. Projects, experience, achievements, and education are arrays in `portfolioData`; add an object to the relevant array, save, and reload the page.

When profile facts or project details change, update `public/llms.txt` as well so its plain-text summary remains consistent with the site.

### Add a project

```js
{
  title: "Project name",
  category: "Web application",
  year: "2026",
  description: "A short description of what it does.",
  technologies: ["React", "TypeScript"],
  visual: "auth",
  featured: false,
  links: [
    { label: "View source", url: "https://github.com/username/project" }
  ]
}
```

Available project preview styles are `codex`, `auth`, and `dj`. Set `featured: true` for the wide featured layout. `technologies` and `links` accept multiple values.

### Add experience

```js
{
  period: "Jan 2025 — Present",
  title: "Organization or project",
  role: "Your role",
  type: "Full-time",
  description: "A short summary of your work.",
  highlights: ["A result, responsibility, or useful detail."]
}
```

`highlights` is optional. Set `type` to values such as `Full-time` or `Internship`.

### Add an achievement

```js
{
  year: "2025",
  title: "Competition or award",
  recognition: "Team winner",
  description: "A short description of the achievement.",
  scale: "18,000+",
  scaleLabel: "people registered"
}
```

Use the `scale` and `scaleLabel` fields for a notable participation or impact figure; otherwise set them to an empty string.

### Add education

Add entries to the `education` array using the same timeline fields:

```js
{
  period: "Dec 2021 — Sep 2025",
  title: "Punjab Engineering College",
  role: "Bachelor of Technology · Electrical",
  type: "Degree",
  description: "Activities, societies, or other details."
}
```

The project and timeline markup is generated by shared helpers in `content.js`; layout lives in `index.html`, responsive styling in `style.css`, and the Three.js hero is in `scene.js`.
